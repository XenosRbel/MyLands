# Game quality
1. Read `AGENT.md`.
2. Select the impacted gameplay flow.
3. Trace the UI action to the API command.
4. Confirm server authority and idempotency.
5. Confirm all affected localization keys.
6. Test the success and error states.
7. Test small screens and reduced motion.
8. Validate the Game Pack.
9. Run available tests.
10. Document unverified behavior.
