# Game design audit
1. Identify the target player journey.
2. Trace every resource source and sink.
3. Document construction and research prerequisites.
4. Compare progression with the game rules.
5. Check time-to-first-action and time-to-first-reward.
6. Check market and transport abuse paths.
7. Verify loss conditions and combat outcomes.
8. Check game speed and retention assumptions.
9. Mark unverified mechanics as proposed.
10. Create measurable acceptance criteria.
