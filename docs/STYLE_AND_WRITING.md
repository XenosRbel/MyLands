# Controlled technical writing

Use ASD-STE100 principles for instructions and documentation.
This repository follows a project writing profile. It does not claim formal ASD-STE100 certification.

## Rules
- Use one action per instruction.
- Limit each sentence to 20 words.
- Use active voice.
- Use one term for each concept.
- Define abbreviations on first use.
- Avoid implied steps.
- Name the file, command, or target state.
- Mark assumptions as assumptions.
- Separate verified behavior from proposed behavior.
- Keep user instructions and developer specifications in separate sections.

## Documentation checks
1. Check every instruction for a single action.
2. Check sentences for the 20-word limit.
3. Check command names against the repository.
4. Check user-visible terms against the localization tables.
5. Keep links and evidence next to each factual claim.
