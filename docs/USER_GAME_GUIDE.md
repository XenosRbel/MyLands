# Player guide

## Start
1. Open the game.
2. Select a world.
3. Select a people.
4. Enter your settlement.

## Manage the settlement
1. Open **City**.
2. Select a building.
3. Review its costs.
4. Start construction.
5. Monitor the construction queue.

## Explore
1. Open **Map**.
2. Select a location.
3. Review the target information.
4. Open **Army** to inspect your troops.
5. Use **Missions** to send an available expedition.

## Sound and animation
1. Select the music symbol in the upper bar to enable sounds.
2. Select the symbol again to disable sounds.
3. Open **Profile**.
4. Enable **Reduce animations** when needed.

## Troubleshooting
- Use **Retry** after a connection error.
- Check the resource bar before starting construction.
- Check the mission queue before sending more troops.
- Never share your account password.
