# Временные спрайты из энциклопедии

Дата: 2026-11-01. Скрипт: `scripts/fetch_wiki_sprites.py`.

## Основание

Заказчик сообщил, что проект — демонстрация для правообладателя, а исполнитель работает как его подрядчик.
Письменное разрешение в репозиторий не передано. Основание записано со слов заказчика и не проверено.

## Правила использования

1. Файлы нужны только для локальной отладки и тестов.
2. Файлы сохраняются в `art-reference/wiki-temp/`.
3. Каталог исключён из git. Файлы не попадают в историю и в ветки.
4. Файлы не входят в сборку клиента и в Game Pack.
5. Перед релизом заменить все временные файлы оригинальной графикой.
6. Решение D-04 (оригинальные спрайты) остаётся целью релиза.

## Запуск

Скрипту нужен доступ в интернет. В среде агента сеть для терминала закрыта, поэтому запускает его человек.

```bash
python3 scripts/fetch_wiki_sprites.py --dry-run
```

```bash
python3 scripts/fetch_wiki_sprites.py
```

Первая команда перечисляет картинки и записывает `manifest.json` без загрузки.
Вторая команда скачивает файлы с паузой 0,5 с между запросами.
Манифест содержит страницу, адрес, предполагаемую расу по префиксу имени, размер и SHA-256.

## Сопоставление с путями пака

Раса определяется по префиксу имени файла: `e` — эльфы, `de` — демоны, `dr` — тёмные эльфы, `wiz` — волшебники, `el` — элементали, `un` — нежить, `chi` — химеры, `m` — монстры, без префикса — рыцари.
Сопоставление с `target_path` из [art-missing.csv](../modernization/art-missing.csv) выполняется отдельным шагом после загрузки.
