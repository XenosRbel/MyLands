# Задание на новую графику My Lands

Задача: [T-034](../../tasks/T-034.md). Исполнители: модели Codex под контролем ревью.
Инвентарь: [art-inventory.csv](art-inventory.csv). Решения заказчика: [TARGET_PROFILE.md](TARGET_PROFILE.md).

## 1. Правила

1. Вся графика новая и оригинальная. Спрайты оригинала не копируются и не обводятся.
2. Формат итоговых файлов: WebP или PNG. SVG в видимой игровой графике запрещён (`AGENT.md`).
3. Заглушки получают метку `PROTOTYPE` и не считаются утверждённым искусством.
4. Смена расширения файла не означает художественной приёмки.
5. Размеры в инвентаре имеют статус `PROPOSED`. Их утверждает ревью до массового производства.
6. Каждый файл получает запись в [ASSET_PROVENANCE.md](../art/ASSET_PROVENANCE.md).
7. Проверка `npm run check:art` проходит после каждой партии.

## 2. Опорная композиция

Композиция берётся из [FORUM_SCREENSHOTS_SERVERS.md](../reference/mylands/FORUM_SCREENSHOTS_SERVERS.md), раздел 5.
Она совпадает с утверждённым визуальным контрактом проекта: левая навигация, правые очереди, верхние ресурсы, нижний гарнизон.
Опорный экран — 1268×884 пикселей. Это размер наблюдённого скриншота, а не обязательство.

## 3. Требования к ассетам

| Требование | Значение |
|---|---|
| Фон | Прозрачный для спрайтов; сплошной для городских фонов и террейна |
| Alpha | Чистые края без белого ореола; проверка на тёмном и светлом фоне |
| Точка привязки | Центр основания спрайта |
| Освещение | Источник сверху-слева для всех спрайтов |
| Состояния здания | Готово, строится, улучшается, разрушено |
| Состояния кнопки | Обычная, наведение, нажата, недоступна |
| Уровни зданий | Девять уровней различаются силуэтом или деталью, а не только цветом |
| Расы | Восемь рас: рыцари, эльфы, волшебники, элементали, демоны, тёмные эльфы, нежить, химеры |
| Читаемость | Объект узнаётся при 50% масштабе |

## 4. Порядок работы

1. Инвентарь сопоставляется с сущностями паков (карточка ML-G01).
2. Модель создаёт пробную партию из трёх файлов на тип.
3. Ревью проверяет контактный лист и снимок в браузере.
4. После одобрения запускается серия на все расы.
5. Приёмка записывает лицензию, источник и дату.

## 5. Проверка соответствия

- Файл отсутствует в инвентаре — файл отклоняется.
- Файл похож на оригинальный спрайт — файл отклоняется и пересоздаётся.
- Файл не имеет записи о происхождении — файл отклоняется.
- Прототип без метки `PROTOTYPE` — файл отклоняется.

## 6. Граница прототипов

Простые миниатюры допустимы для проверки раскладки.
Они создаются в WebP или PNG и хранятся отдельно от финальных ассетов.
Миниатюры не выдаются за оригинальные или подтверждённые ассеты.
