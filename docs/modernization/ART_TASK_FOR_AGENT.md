# Задание агенту-художнику: недостающие спрайты My Lands

Дата: 2026-11-01. Список: [art-missing.csv](art-missing.csv) — 2095 позиций.
Правила и размеры: [ART_BRIEF.md](ART_BRIEF.md). Решения заказчика: [TARGET_PROFILE.md](TARGET_PROFILE.md).

## 1. Что нужно сделать

1. Создай графику для всех позиций со статусом `MISSING`.
2. Работай партиями в порядке приоритета: P0, затем P1, затем P2.
3. Сохраняй файл по пути из колонки `target_path`.
4. Используй WebP с alpha там, где колонка `alpha` равна «да».
5. Для каждого файла добавь запись в `docs/art/ASSET_PROVENANCE.md`.
6. После каждой партии запусти `npm run check:art`.
7. После каждой партии собери контактный лист и просмотри его.

## 2. Запреты

- Не копируй и не обводи спрайты оригинала.
- Не создавай SVG для видимой игровой графики.
- Не выдавай заглушку за утверждённый ассет. Помечай её `PROTOTYPE`.
- Не меняй пути и размеры без записи в отчёте.

## 3. Состав по приоритетам

| Приоритет | Позиций | Состав |
|---|---|---|
| P0 | 445 | Рыцари и Эльфы: здания в трёх ступенях и состоянии «строится»; юниты этих рас; ресурсы; кристаллы; террайн; рамка интерфейса; фоны городов |
| P1 | 1315 | Остальные шесть рас; портреты героев; предметы; объекты карты; остальной интерфейс |
| P2 | 335 | Разрушенные здания; античные руны; мастерские кристаллы |

## 4. Правила для зданий

- Здание имеет три визуальные ступени: уровни 1–3, 4–6, 7–9.
- Ступени различаются силуэтом или крупной деталью, а не только цветом.
- Состояние «строится» показывает леса и недостроенный объём.
- Состояние «разрушено» показывает руины той же формы.
- Здания одной расы делят палитру и материалы.
- Здания разных рас различаются силуэтом.

## 5. Правила для войск

- Каждое имя из [units-roster.csv](../reference/mylands/units-roster.csv) требует отдельную иконку.
- Иконки одной категории и одной расы показывают рост силы по уровням.
- Монстры образуют отдельную «расу» с мрачной палитрой.
- Серое состояние иконок строит клиент. Отдельный файл не нужен.

## 6. Критерии приёмки

1. Каждая позиция P0 имеет файл по пути из списка.
2. `npm run check:art` проходит.
3. Контактный лист проверен человеком.
4. Нет SVG в видимой графике.
5. Каждый файл имеет запись о происхождении.
6. Позиции P1 и P2 остаются со статусом `MISSING`, пока не созданы.

## 7. Отчёт агента

Агент возвращает число созданных файлов по приоритетам, список отклонённых и список нарушений правил.
Агент не отмечает позицию готовой без запуска проверки.
