# My Lands: точные таблицы зданий, войск, террайна

Дата исследования: 2026-11-01. Профиль: `ru.mlgame.org/wiki-ru`.
Метод: `DOM_EXTRACT`. Страницы разобраны по HTML в браузере, пустые ячейки сохранены.
Данные (67 страниц): [tables-dom.txt](tables-dom.txt), [tables-dom.json](tables-dom.json), [units-roster.csv](units-roster.csv).
Закрывает карточки ML-R03, ML-R04 и часть ML-R08.

## 1. Почему прежние выводы заменены

Текстовый конвертер терял пустые ячейки.
Два агента и [SUPPLEMENT_PAGES.md](SUPPLEMENT_PAGES.md) назначали ресурсы колонкам по порядку значений.
Для части уровней это давало неверные колонки.
Пример: у Воскресителя первый ресурс — камень, а не золото.
Таблицы `tables-dom.txt` заменяют прежние `COLUMNS_UNCONFIRMED`.

## 2. Подтверждённая схема колонок

| Элемент | Правило |
|---|---|
| Колонки ресурсов зданий | Золото, дерево, камень, железо, жемчуг — по иконкам заголовка |
| Пустая ячейка | Ресурс не требуется; в данных остаётся пустой |
| Колонка «Кристаллы» | Последовательность иконок цветов; количество не подтверждено |
| Таблицы войск | Атака, здоровье, жалование, золото, дерево, зерно, железо, население, рейтинг |
| Проверка колонок войск | Рейтинг совпадает с формулой `Rating` (золото + ресурсы × курс) |

Проверенные примеры рейтинга:

- Воин 3 ур.: 10 + 12 × 14 + 15 × 21 = 493.
- Лекарь 1 ур.: 25 + 200 × 14 + 35 × 21 = 3560.
- Маг 1 ур.: 80 + 107 × 21 = 2327.
- Носильщик 1 ур.: 3 + 25 × 3 = 78.

Курсы взяты из страницы `Rating` (зерно 14, железо 21); курс дерева 3 выведен из таблицы и помечен `INFERRED`.

## 4. Войска

Ростер: 8 категорий × 8 рас × 4 уровня + монстры × 3 уровня = 280 записей.
Категории: носильщики, воины, всадники, летающие, стрелки, лекари, наёмники, маги.
Категория выведена из префикса имени картинки и порядка заголовков; проверка на совпадение пройдена.

Таблицы параметров: 24 таблицы.

| Группа | Таблиц | Уровни |
|---|---|---|
| Войска игроков | 8 | 1–4 |
| Монстры | 8 | 1–3 |
| Монстры клановых замков | 8 | 1–4 |

Подтверждено:

- Параметры одинаковы для всех рас, кроме расовых вариантов в скобках ячейки, например `(Рыцари:100)`.
- Нотацию «Раса:значение» страница не объясняет. Статус: `UNKNOWN`.
- Таблица Стрелка содержит три пары колонок «Экономический сервер». Это профильные варианты атаки, здоровья и населения.
- Параметр «Защита» у всех войск равен 0.
- Дезертирство: 0,5% юнитов в час при нехватке жалования.
- Жалование на миссии: коэффициент скорости 1; 1,25; 1,5; 2.
- Снижение жалования на шахтёрском и боевом профилях: до −99,74% и −99,34% (по `UnitParametrs`).

## 7. Что не закрыто

| Область | Статус |
|---|---|
| Размер империи | Решение заказчика: 90 × 30 королевств (x 1..90, y 1..30); совпадает с адресами на скриншотах (x до 39, y до 13). Поля королевства 9 × 9 = 81: `PROPOSED` (видны номера до 61, соседство по ширине 9). Метрика расстояния `UNKNOWN` |
| Поля королевства | Пример соседства из `Sectors` указывает построчную нумерацию с 9 полями в ряду (`INFERRED`) |
| Количество кристаллов | Трактовка «повтор значка = единица» и значения проектируются в [CRYSTAL_ECONOMY.md](../../modernization/CRYSTAL_ECONOMY.md), `PROPOSED` |
| Единица урона простой башни | За раунд: страница `Magic_Tower` пишет «башни бьют каждый раунд» |
| Нотация «Раса:значение» | Значение для указанной расы вместо базового; поддержана в схеме Game Pack как `{base, races}` |
| Таблицы остальных страниц | Дамп охватывает все страницы, где есть таблицы из трёх строк и больше; прочие страницы — проза |

## 8. Прочитанные дополнительно страницы FAQ

Ответы получены агентом через текстовый конвертер, числа без таблиц:

- `Autodel`: удаление персонажа через 7–42 дня в зависимости от центра здания; ворота при мятеже открываются в 20:00 серверного времени.
- `Progul`: через 4 дня отсутствия 80% рабочих покидают здания.
- `Mess_dur`: сообщения хранятся 5 дней или до лимита 1000 писем.
- `Fraction`: отступник — 7 дней; −25% атаки против своей фракции, −50% против своей расы.
- `Serverchange`: перенос между серверами — на портале в окне выбора серверов.
