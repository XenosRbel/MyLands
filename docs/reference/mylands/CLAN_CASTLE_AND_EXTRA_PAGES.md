## 1. Как найдены страницы

- `robots.txt` не содержит ссылки на карту сайта. Он закрывает только поиск.
- `TitleIndex` перечисляет 84 страницы.
- `FullRecentChanges` перечисляет 230 страниц, включая служебные.
- Страницы с суффиксом `_kz` описывают здания Кланового замка.

### Дипломатический корпус замка (`Diplomat_kz`)

- В одном замке можно построить один корпус.
- Корпус даёт до трёх мирных договоров и до трёх объявлений войны.
- После мирного договора игроки двух кланов не атакуют друг друга.
- После мирного договора купцы между клановыми владениями движутся вдвое быстрее.
- Замок получает 1 очко мира за каждые 1 500 000 ресурсов в золотом эквиваленте, купленных членами клана-партнёра.
- Расторжение договора возможно в течение 24 часов; инициатор может отменить расторжение.
- Потеря последнего замка расторгает все договоры.
- Условия объявления войны на странице обрезаны в извлечении. Статус: `UNKNOWN`.

### Заброшенная гильдия купцов (`Z_merch_guild`)

- Первый уровень есть в любой Шахте изначально.
- Таблица: уровни 1–7, количество купцов 1–7, время тренировки 60, 50, 40, 30, 20, 10, 5 мин.

## 3. Руны (`Alchemy2`)

- Второй уровень науки «Алхимия» разрешает грабить руны в Стоунхенджах и совершать ритуалы.
- Видов рун девять. В таблице извлечено девять эффектов (Фэо, Ур, Торн, Ио, Рад, Тир, Гифу, Йар, Хегль).
- На один артефакт можно нанести до пяти рун, включая одинаковые.
- Руны нельзя ограбить у других игроков. Их можно продать торговцу артефактами.
- Стоунхендж находят только Сюзерены с помощью исследователей.
- Полный текст страницы обрезан. Правила восстановления рун — `UNKNOWN`.

## 4. Автоисследование, очереди, аккаунт

| Страница | Факты |
|---|---|
| `ExploreTurn` | Автоисследование задаётся в Экспедиционном корпусе: координаты королевства, флаг «Подземелье», скорость. Выше скорость — выше шанс смерти исследователя |
| `ScienceTurn` | В очередь наук добавляется до 4 наук |
| `BuildingsTurn` | В очередь построек добавляется до 4 зданий |
| `Ch_race` | Расу можно сменить один раз через Советника; либо удалить персонаж (через 7 суток) |
| `Del_pers` | Удаление персонажа происходит через 7 суток, если не отменить |
| `City_ren` | Переименование города — в Центральном здании |
| `Start3`, `Start4` | Советник выдаёт войска и ресурсы; карта империи расположена под картой королевства |
| `GiftBG` | Подарок ЧЖ игроку через круговое меню города |
| `Auto_enter` | Флаг «Входить автоматически»; адрес сервера вида `имя_сервера.ru.mlgame.org` |

## 5. Платёжные страницы

Страницы `PayPal`, `SMS`, `MASTERCARD`, `VISA`, `Qiwi`, `Yandex_money`, `PlatBox`, `Webmoney`, `WebmoneyCard`, `WMU`, `Step_10` описывают шаги оплаты.
Шаги: выбрать способ, выбрать тариф, оплатить, следовать инструкциям провайдера.
Тарифы и цены на страницах не указаны. Статус: `UNKNOWN`.
Для Realmforge нужен только mock-провайдер. Реальные провайдеры не переносятся.
