## 3. Система серверов

Источник: `Serv`, ревизия 52 (`PAGE_READ`, подробности в [COMBAT_HEROES_SOCIAL.md](COMBAT_HEROES_SOCIAL.md), раздел 7).

- Профилей на wiki восемь: шахтёрский, боевой, экономический, тактический, геройский, стратегический, оперативный, Война фракций.
- Профиль меняет добычу, жалование, героев, защиту, храм, услуги и условия победы.
- Профиль нельзя свести к одному множителю скорости.
- Игрок выбирает сервер при входе. Правило выбора — `FAQ` (ответ не прочитан), `UNKNOWN`.
- Финансовый счёт портала переводит ЧЖ на выбранный сервер (`Mistakes`).
- Тот же счёт выводит ЧЖ с платных серверов на портал (`Mistakes`).
- Кошелёк портала общий; ЧЖ сервера принадлежит аккаунту на сервере (`BlackPearl`).
- Один персонаж на игрока на сервер (`Rules`).
- Реферальная программа суммирует доход по всем серверам (`Referal`).
