# Source Register: Agent A1 (Game Researcher)

Project: research into the public materials of *My Lands: Black Gem Hunting*, done to design an original game. Only systems are reconstructed. No names, art or texts are reused.
Access date for every entry: **2026-10-31**.

## Method and a major limitation (read first)

- In this research session, direct page fetching (WebFetch) was **blocked by the session's network policy**. DNS resolution failed for every host tried: `steam.mlgame.org`, `us.mlgame.org`, `uk.mlgame.org`, `store.steampowered.com`, `steamcommunity.com`, `en.wikipedia.org` and `mylandsgame1.blogspot.com`. The proxy status endpoint was also denied.
- All evidence was therefore collected with the **WebSearch tool**. It returns search-index extracts (titles, URLs and short snippets) plus a machine summary of those snippets. Quotes in our docs are taken from those snippets. They are **not** from a full read of each page.
- Consequences:
  - We have **not read any page end to end**. Tables such as per-level costs and times are usually missing from snippets, so many numeric details are UNKNOWN.
  - A snippet may come from an older cached revision. Several results were flagged as roughly 300–2,000 days old.
  - The official encyclopedia runs as many regional mirrors with different game versions. Examples: `steam.mlgame.org/wiki-en`, `mlgame.co.uk/wiki`, `mlgame.co.uk/wiki-uk`, `uk.mlgame.org/wiki-uk`, `mlgame.us/wiki`, `mlgame.us/wiki-us`, `us.mlgame.org/wiki-us`, plus ru/fr/es/it/bg/cz/hu mirrors. Content differs between them.
- Confidence policy:
  - **high**: two or more mirrors or sources agree, and a direct snippet quote exists.
  - **med**: a single official-encyclopedia snippet.
  - **low**: forum or fan sources, non-English mirrors only, or wording that is unclear in the summary.
- **To re-verify**, allow the hosts `steam.mlgame.org`, `*.mlgame.org`, `mlgame.co.uk`, `mlgame.us`, `store.steampowered.com` and `steamcommunity.com` in the session network settings. Then re-fetch each page listed below.
