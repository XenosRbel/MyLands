# T-032 — Общий harness для Codex и Claude Code

- **Цель**: воспроизводимая рабочая среда обоих агентов внутри репозитория.
- **Зависимости**: T-001; существующие правила `AGENT.md` и команды `Makefile`.
- **Модули**: `.agents/`, `.codex/`, `.claude/`, `scripts/harness/`, `Makefile`, документация.
- **Дизайн**: [Общий harness](../docs/superpowers/specs/2026-11-01-agent-harness-design.md).
- **Критерии приёмки**:
  - Оба агента используют `AGENT.md` как источник инженерных правил.
  - Общие команды выводят контекст, проверяют зависимости и запускают обязательные проверки.
  - Настройки используют подтверждённые возможности установленных версий инструментов.
  - Хуки проверены входными JSON-событиями, включая ошибочные сценарии.
  - Защита разрешает добавление миграций и генерацию OpenAPI штатной командой.
  - Документация объясняет запуск, ограничения, MCP и локальное состояние задачи.
  - Глобальные настройки, секреты и продуктовый код остаются вне этой задачи.
- **Обязательные проверки**: тесты harness; разбор JSON/TOML; `make lint`; `make test`; `make packs`.
- **Дополнительные проверки**: запуск новых сессий обоих агентов, если доступна авторизация.
- **Результат**: Готово
Обязательные проверки зелёные 2026-11-01. Живая активация хуков в клиентах не подтверждена, см. Ограничения.
- **Ограничения**: реальные сессии и доверие Codex-хукам не подтверждены (дополнительная проверка критериев); E2E не запускался для инфраструктурного изменения. Приёмку выполнил тот же агент, без независимого проверяющего.

## Исключения

- `make lint` блокируют `server/internal/game/economy.go`, `game_test.go` и `specialization_test.go`.
  Проверка содержимого из `HEAD` подтвердила, что все три файла уже требовали gofmt.
  Эти файлы не изменены: продуктовый код находится вне согласованного объёма.
- Новые интерактивные сессии клиентов не запущены.
  JSON-проверки не доказывают автоматическую активацию хуков.
  Codex требует проверки доверия через `/hooks`; `claude doctor` сообщил об отсутствии входа.
- `make e2e` не запускался: пользовательские игровые потоки не менялись.
- Диагностика БД после удаления временного контейнера требует собственного тестового PostgreSQL.
- Хуки не гарантируют защиту от произвольных программ и неподдерживаемых путей инструментов.
