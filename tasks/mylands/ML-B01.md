# ML-B01 — БД: нормализация resource_ledger

- **Спринт**: S1 Перенос данных
- **Трек**: backend-db
- **Цель**: Заменить JSONB-дельту журнала ресурсов нормализованными строками с внешними ключами (рекомендация R-1).
- **Зависимости**: ML-D01
- **Модули**: `server/migrations/, server/internal/game/`
- **Источник**: DB_DESIGN R-1
- **Критерии приёмки**:
  - Новая таблица строк журнала с FK на игрока, город и ресурс.
  - Старые данные переносятся без потерь.
  - Сумма строк совпадает с запасами.
- **Обязательные тесты**:
  - Миграция на пустой БД и поверх 0001/0002.
  - Интеграционный тест леджера.
  - Гонка двух списаний.
- **Результат**: Выполнена частично. Миграция 0003 добавила `resource_ledger_entries` (FK на журнал, `amount<>0`, перенос из JSONB) и индексы по `at`. Go пишет и читает новую таблицу. FK на игрока и город уже есть с 0002 (`NOT VALID`). FK на ресурс невозможен: ресурсы лежат в Game Pack. Столбец `delta` оставлен как устаревший. `make test-go` с -race и `make lint` прошли. `make e2e` не запускался.
- **Ограничения**: Значения со статусом `UNKNOWN` не заменяются собственными.
