# ML-B04 — БД: кристаллы, руны, предметы героя

- **Спринт**: S1 Перенос данных
- **Трек**: backend-db
- **Цель**: Склад кристаллов игрока, руны и инвентарь героя.
- **Зависимости**: ML-B01, ML-D01
- **Модули**: `server/migrations/`
- **Источник**: CRYSTAL_ECONOMY
- **Критерии приёмки**:
  - Кристаллы хранятся строками по типу.
  - Выдача пишет журнал.
  - Слоты артефактов уникальны.
- **Обязательные тесты**:
  - Тест ограничений.
  - Тест журнала.
- **Результат**: Выполнена. Миграция 0006: `crystal_stocks`, `crystal_ledger` (триггеры остатка и добавления, связь с `resource_ledger_entries`), `hero_artefact_slots` с триггером на `items` и переносом, `item_runes`. Тесты: `server/migrations/crystals_test.go`. Старые кристаллы в `cities.resources` не перенесены. Код Go не переключён.
- **Ограничения**: Значения со статусом `UNKNOWN` не заменяются собственными.
