# ML-B07 — БД: конкурентные mock-платежи

- **Спринт**: S1 Перенос данных
- **Трек**: backend-db
- **Цель**: Проверить два одновременных подтверждения одного платежа.
- **Зависимости**: ML-D01
- **Модули**: `server/migrations/, server/internal/game/`
- **Источник**: DB_DESIGN F
- **Критерии приёмки**:
  - Два соединения не удваивают зачисление.
- **Обязательные тесты**:
  - Тест с двумя соединениями и -race.
- **Результат**: Готово
  Тест `server/migrations/payment_concurrency_test.go` (-race), миграция `0009_purchase_matches_order.sql` исправляет найденный дефект. Описание: `DB_DESIGN.md`, раздел 9. Код Go `server/internal/game` не использует платежи, поэтому проверена только база.
- **Ограничения**: Значения со статусом `UNKNOWN` не заменяются собственными.
