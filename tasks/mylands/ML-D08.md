# ML-D08 — Конфигурация серверного профиля

- **Спринт**: S1 Перенос данных
- **Трек**: backend-data
- **Цель**: Описать профиль и бонусы сервера в конфигурации.
- **Зависимости**: ML-D01, ML-R09
- **Модули**: `server/internal/platform/, packs/`
- **Источник**: Serv
- **Критерии приёмки**:
  - Бонусы задаются в конфигурации.
  - Формулы остаются в движке.
  - Один сервер запускается из конфигурации.
- **Обязательные тесты**:
  - Тест загрузки конфигурации.
- **Результат**: Выполнена в `mylands/spec-data`. Пак `mylands`: восемь профилей, четыре `paramDefs` (`PROPOSED`), профиль `combat` по умолчанию (`PROPOSED`). Конфигурация: `RF_SERVER_PROFILE`, `RF_PROFILE_BONUSES`, проверка `pack.ResolveProfile`. Тесты: загрузка конфигурации, неизвестный профиль, бонус вне диапазона. Не сделано: запись `profile_id` в мир (миграции ведёт другой агент) и использование множителей движком (ML-M19).
- **Ограничения**: Значения со статусом `UNKNOWN` не заменяются собственными.
