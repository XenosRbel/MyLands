# ML-R08 — Матрица террайнов и поля королевства

- **Спринт**: S0 Исследование
- **Цель**: Получить размеры империи, королевства и значения террайнов.
- **Зависимости**: нет
- **Модули**: `docs/reference/mylands/`
- **Источник**: WORLD W-01
- **Критерии приёмки**:
  - Размеры и нумерация записаны.
  - Матрица значений полная.
- **Обязательные тесты**:
  - Проверка полноты матрицы.
- **Результат**: Частично. Матрицы террайна получены. Размеры империи и королевства остаются UNKNOWN.
- **Ограничения**: Значения со статусом `UNKNOWN` не заменяются собственными.
